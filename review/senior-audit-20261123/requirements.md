# Сверка требований — 23 ноября 2026

Проверены описания PR №1–5 и доступные предыдущие обсуждения релиза, писем и консультаций. GitHub API вернул пустые списки комментариев/ревью для всех пяти PR и пустой список Issues. Поэтому требования, которые владелец называл «в комментариях», сопоставлены с предыдущими обсуждениями; несуществующие комментарии не приписываются репозиторию.

Также прочитан исходный дизайнерский архив `DZ-Emails(1).zip`: README, subjects.json, HTML/Blade и текстовые версии обоих продуктов. Архив предлагает пять событий и два напоминания через 24/72 часа. Более позднее прямое требование владельца имеет приоритет: **четыре события, одно напоминание через 12 часов**. Второе напоминание не включается.

**Решение по релизу: NO-GO до завершения интеграции RC2–RC4 и проверки свежего состояния сервера.** Патч закрывает воспроизведённые дефекты, но не заменяет работу по подключению четырёх событий писем, маршрутизации отказов генератора, внешней доставке и серверному переключению с откатом. Страницы Figma не объявляются полностью принятыми по одному скриншоту или по прохождению backend-тестов.
