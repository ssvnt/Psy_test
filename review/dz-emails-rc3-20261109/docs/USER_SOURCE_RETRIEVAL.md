# Требуется оригинал DZ-Emails(1).zip для окончательной редакторской приёмки

Архив существует как вложение интерфейса, но не монтируется по указанному в сообщении пути `/mnt/data/DZ-Emails(1).zip`. Точное содержимое не считано. Не принимать восемь новых черновиков за тексты пользователя.

**Одно действие на Windows:** откройте ZIP штатным архиватором и прикрепите сюда **все HTML/TXT/MD/DOCX файлы писем непосредственно, без ZIP**. Если внутри только HTML, достаточно этих HTML. Это позволяет сохранить стиль и структуру исходных писем. Если HTML очень много, можно прикрепить их несколькими вложениями. Никаких секретов или реальных списков клиентов отправлять не нужно.

После получения оригиналов нужно выполнить матрицу сравнения: тексты, темы, логотип/цвета, CTA, ссылки, оба продукта, consent/отписка, время, SLA и anti-duplicate. Затем сделать отдельный code PR с реальными текстами — не внедрять из предложенного каталога автоматически.
