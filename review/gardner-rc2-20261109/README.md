# DZ GARDNER RC2 — QA v1.1, ошибки и автономное восстановление (STAGING ONLY)

**Дата:** 2026-11-09. Архитектура основана на присланных в чате разделах 18 и 19. Полный серверный оригинал архитектуры не обнаружен; сохранён *восстановленный* нормативный документ, не выдуманные разделы 1–17.

## В пакете

- `architecture/*` — развёрнутые требования QA v1.1 и неблокирующего конвейера.
- `src/dz_rc2/policy.py` — классификатор причин остановки (включая budget, timeout, transport, 429, lease, QA, integrity).
- `src/dz_rc2/quality.py` — подготовка адресных задач редактора только по уже сохранённым полям, локальная нормализация, защита чисел/отрицаний/остальных ключей.
- `src/dz_rc2/store.py` — изолированная SQLite state machine: immutable checkpoints, nonblocking per-chunk QA, события MAX без отправки, журнал затрат с unknown hold, lease/restart, owner-attention.
- `src/dz_rc2/simulator.py` — синтетическая проверка сценария Гарднера 106 (61/61; 51/181 failures), без использования данных реального ребёнка.
- `tests/*` — 58 выполненных Python-тестов и 20 PHP-контрактных проверок на ошибках, оплате, идемпотентности, восстановлении, QA, параллельных воркерах и ограничениях бюджета.
- `fixtures/*` — только искусственные значения.
- `docs/*` — карта изменений в Laravel и дальнейшие интеграционные испытания.

## Запуск после распаковки на отдельной машине или в /root, НЕ в /var/www

```bash
bash scripts/run_offline_tests.sh
```

`RC2_OFFLINE_QA_AND_RECOVERY_TESTS=PASS` подтверждает только алгоритмический прототип и локальные SQLite-тесты. Для полноценного интеграционного теста Laravel с фиктивными внешними сервисами нужен отдельный серверный стенд; этот архив не содержит `--deploy`, `--migrate`, сетевых отправителей и кода изменения продакшен-файлов.

**Важная проектная граница:** первичная генерация — DeepSeek; по пользовательскому требованию редактор — GigaChat, с отдельным финансовым журналом и реальными humanizer-ru + pishi-normalno. Это **контракт**, пока не выполненная облачная интеграция.

## PHP-контракты для будущего Laravel-адаптера

`php/App/Services/Children/V2/GardnerV22/Recovery/*` — два чистых класса PHP: классификация остановок и адресный QA-план. Синтаксис проверен на PHP 8.4; 20 PHPUnit-подобных (без framework) проверок прошли. Скрипт cross-runtime сравнивает 25 сценариев с Python. **Никакой записи в живое приложение.**

`docs/QA_POLICY_INTEGRATION_SCHEMA_DRAFT.md` описывает будущие миграции, не исполняя их. `scripts/rc2_readonly_host_preflight.sh` читает лишь инвентарь сервисов и проверяет PHP-синтаксис staged RC1. `scripts/qa_readonly_inspect.py --file /private/path/quality.json` выводит только идентификаторы expert-полей и машинные коды, без ответов ребёнка.
