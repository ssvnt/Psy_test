## Граница безопасности

**Public GitHub push = NO-GO.** Переход `ssvnt/Psy_test/main` на полноценный исполняемый Laravel/Vue-проект требует проверки секретов в исходных байтах и происхождения ресурсов. Не выкладывать исходный TAR/ZIP даже в review-ветку публичного репозитория. Переход в private-репозиторий не отменяет обязанности убрать приватные ключи и платёжные идентификаторы из Git.
