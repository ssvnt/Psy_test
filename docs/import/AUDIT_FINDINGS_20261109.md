## Разрешение на публикацию

**NO-GO для публичного GitHub**. Отчёт аудита не содержит доказательства отсутствия всех секретов, индивидуальных ссылок оплаты и не подтверждает право публикации изображений и шрифтов.

Безопасный следующий шаг: создать отдельную приватную staging-копию исходников в `/root` с проверкой архивов; сохранить старую версию `main` и review-ветки RC1–RC4. Изменять публичность репозитория/проводить ручную редактуру и интеграцию — только после этого. Из этого пакета ни один файл не должен автоматически отправляться в GitHub.
